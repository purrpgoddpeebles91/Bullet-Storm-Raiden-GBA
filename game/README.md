# Bullet Storm Raiden — GBA homebrew (v0.2)

Made for GitHub Game Off 2026. A game developed and created by Zachary Peebles.

An original horizontal shoot-'em-up for the Game Boy Advance: "A Dream War".
C + libtonc, built with the Wonderful Toolchain. All art and music are generated by
the scripts in `../tools/` (original content; Gradius/Raiden/DoDonPachi/R-Type/Parodius
are named only as tribute text).

## Build

```sh
export PATH=/opt/wonderful/bin:$PATH      # Wonderful Toolchain (run ../setup-toolchain.sh if missing)
cd game
make assets   # optional: regenerate src/assets.c + src/music_data.c (needs python3 + Pillow)
make          # -> build/BulletStormRaiden.gba (+ .elf/.map)
make dist     # -> ../dist/BulletStormRaiden_v0.2.gba (wf-gbatool fix: title BSRAIDEN, code BSRE, official logo, checksum)
              #    (v0.1 release file in ../dist is kept untouched)
make clean
```

Header settings live in `wfconfig.toml`. The ROM carries the `SRAM_V113` tag so emulators
and flashcarts give it 32 KB battery SRAM.

## Layout

| path | what |
|---|---|
| `src/main.c` | boot, state machine, sprite (OAM) helpers, RNG, integer atan2 |
| `src/game.c` | gameplay: player, weapons, enemies, seeded wave remixer, bosses, HUD, pause |
| `src/menus.c` | title (credits: MADE FOR GITHUB GAME OFF 2026 / A GAME DEVELOPED AND CREATED BY ZACHARY PEEBLES; START RUN / DREAM WORKSHOP / GAME SETTINGS), difficulty, ship select, slot-1 pick, intro dialogue, fork, shop/events, game over, world clear, Dream Workshop |
| `src/run.c` | run state, ship table, power-up pool + meter roll, relics |
| `src/text.c` | BG0 text/UI layer (font built at boot from libtonc sys8 glyphs + drop shadow), video modes, theme loader |
| `src/sound.c` | audio driver: PSG music player, software 4-voice synth (DS-only driver), ARM/IWRAM mixer (resample, tone filter, bit-crush, stereo matrix) -> DirectSound A=left / B=right via a 4-segment ring (timer0 + DMA1/2; buffer swaps from VBlank, Timer1-cascade IRQ or free-running ring) |
| `src/video.c` | video "driver": master palettes + real-time palette shaders / brightness / saturation / temporal dither, HBlank-DMA scanlines & interlace (REG_BLDY darken), hardware mosaic, WIN0 aspect masks / settings preview window, semi-transparent OBJ ghost trails, screen shake, flash control, 30 fps / adaptive frame skip, FPS / CPU meter |
| `src/settings.c` | GAME SETTINGS menu (MAIN / VIDEO / AUDIO / GAMEPLAY pages, live preview scene, VU meters), option tables, SRAM persistence at 0x100 |
| `src/save.c` | SRAM save (dream coins, high score, upgrades, unlocks) with checksum |
| `src/assets.c`, `src/music_data.c` | GENERATED — do not edit; edit `../tools/gen_assets.py` / `../tools/gen_music.py` |

## Controls

D-pad move · A fire (hold; see GAME SETTINGS > GAMEPLAY for auto-fire / A-B swap) · B bomb · L cash in power meter · Start pause (pause shows seed + relics; Select there quits the run).

Debug (for testing): on the title hold L+R and press Select ("DEBUG" appears). Player is invincible,
Select in a stage jumps to the boss, Select during a boss takes 1/3 of its HP, R advances the meter,
and shop/event nodes become deterministic.

## Testing headless

`../tools/runrom` (mGBA via libmgba, source `../tools/runrom.c`) runs the ROM with scripted input and writes PNG screenshots
(and optional WAV via `WAVOUT=file.wav`):

```sh
../tools/runrom build/BulletStormRaiden.gba ../tests/t2.txt ../dist/screens /tmp/save.sav
```
Script commands: `wait N`, `hold KEY+KEY N`, `press KEY`, `shot NAME`. Rebuild the runner with
`gcc -O2 ../tools/runrom.c -o ../tools/runrom -lmgba -lpng` (needs `libmgba-dev libpng-dev`).

## GAME SETTINGS (v0.2)

Title > GAME SETTINGS. UP/DOWN pick, LEFT/RIGHT (or A) change, L/R switch page, B back. Every change applies
instantly and is written to SRAM (offset 0x100, own magic + checksum, so v0.1 saves still load). RESET PAGE /
RESET ALL need A twice. VIDEO/AUDIO/GAMEPLAY pages show a live preview box (Nightjet, enemies, bullets,
parallax stars) drawn through a WIN0 window with the current video settings; menu text stays unshaded so it is
always readable. On the AUDIO page the preview plays the World 1 theme plus shot/explosion/power-up SFX and shows
L/R VU meters of the DirectSound mixer.

These are in-game equivalents: a GBA ROM cannot change the emulator's host driver, GPU shaders or upscaler.

| page | setting | options (default first or marked *) | how |
|---|---|---|---|
| VIDEO | RENDER MODE | HARDWARE*, SOFT DITHER, LINE DOUBLE, INTERLACE | dither: 8-level/channel palette quantise, two palettes alternated each frame (temporal dither); line double: vertical mosaic 2; interlace: HDMA darkens alternate lines, parity flips per frame |
| | SHADER | NONE*, LCD COLOR, CRT WARM, GAME BOY, POCKET, SEPIA, VIRTUAL BOY, NIGHT VISION, INVERTED, HI CONTRAST, DREAM PASTEL, NIGHTMARE | master palettes in RAM, transformed copies written to PAL RAM (only dirty 16-colour banks re-done) |
| | SCANLINES | OFF*, LIGHT, MEDIUM, HEAVY | DMA0 HBlank-repeat writes a per-line REG_BLDY table, BLDCNT darken on all layers; zero CPU |
| | RESOLUTION | NATIVE 1X*, MOSAIC 2X/3X/4X | REG_MOSAIC on BG1-3 + all sprites; BG0 HUD/text stays sharp |
| | BRIGHTNESS | -3..+3 (0*) | gamma curve LUT in the palette transform |
| | SATURATION | 0% GRAY, 50%, 75%, 100%*, 125%, 150% | palette transform |
| | FRAME BLEND | OFF*, LOW, HIGH | previous 1 (LOW) or 2 (HIGH) frames of sprites re-drawn as semi-transparent OBJs (alpha 5/11 or 7/9) in free OAM slots |
| | SCREEN SHAKE | OFF, LOW*, FULL | BG2/BG3 scroll + sprite offset on bombs, hits, big kills, boss deaths |
| | SCREEN FLASH | ON*, SOFT, OFF | backdrop flash white / 35% / none |
| | FRAME RATE | 60 VSYNC*, 30 FPS, ADAPTIVE | 30: logic every frame, display (OAM/palette/scroll) every 2nd; adaptive: if logic overruns a frame, skip one render to catch up |
| | ASPECT | FULL 3:2*, 4:3 PILLAR, 16:9 CINEMA, FRAMED | WIN0 over the playfield (gameplay only), black BG1 outside, HUD text stays visible |
| | BULLETS | NORMAL*, HI-VIS RED, HI-VIS PINK | enemy bullets use their own OBJ palette (bank 15), recoloured white-core/bright-rim, bypassing the shader |
| | PERF METER | OFF*, FPS, CPU, FPS + CPU | sprite text; CPU = VCOUNT lines used by logic+mix per frame (peak of 30 frames) |
| AUDIO | AUDIO DRIVER | DS + PSG*, PSG ONLY, DS ONLY | PSG music + mixed DS SFX / PSG music + SFX as PSG sweep/noise recipes (steal ch1/ch4) / music re-synthesised in software and mixed with SFX |
| | SAMPLE RATE | 6689, 10512, 13379*, 18157, 21024, 31536 Hz | timer0 period; all are exact multiples of 16 samples per frame; SFX resampled 16.16 |
| | BIT DEPTH | 8-BIT*, 6, 4, 2 | output mask |
| | LATENCY | LOW 1F, NORMAL 2F*, HIGH 3F | mix-ahead segments in a 4-segment ring |
| | AUDIO SYNC | VSYNC*, TIMER IRQ, FREE RUN | DMA re-pointed each VBlank / by a Timer1-cascade IRQ every N samples / only at ring wrap |
| | STEREO | STEREO*, MONO, SWAP L/R, WIDE | per-voice pan gains in the mixer + PSG L/R enables; WIDE adds side boost |
| | TONE | BRIGHT, NORMAL*, WARM, MUFFLED | pre-emphasis / none / 1-pole / 2-pole lowpass |
| | MUSIC VOLUME, SFX VOLUME | 0..10 (10*) | PSG master volume + DMG ratio; mixer gains |
| | MUSIC STYLE | AUTO ROUTE*, ALWAYS DREAM, NIGHTMARE | remaps the World 1 theme variant |
| GAMEPLAY | AUTO-FIRE | OFF (HOLD)*, TOGGLE, ALWAYS ON | |
| | BUTTONS | A FIRE B BMB*, B FIRE A BMB | stages only; menus keep A = OK |
| | HUD LAYOUT | FULL*, MINIMAL | one-line HUD |

In DS + PSG mode, sample rate / bit depth / tone shape the DirectSound path (sound effects); choose DS ONLY to
hear them on the music too.

runrom script extra commands: `wav PATH` starts a WAV capture, `wavend` closes it.
