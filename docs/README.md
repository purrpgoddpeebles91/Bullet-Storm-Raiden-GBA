# Bullet Storm Raiden: web player (static site)

Serve this folder as static files (GitHub Pages: Settings > Pages > deploy from branch, folder `/site` or copy it to `/docs`). Everything runs client-side; no build step.

Regenerate from a new ROM: `python3 tools/build_web_player.py dist/BulletStormRaiden_vX.Y.gba --skins`
